# QDM 资源下载助手（Chrome / Edge）

扩展版本 **0.2.0**，桌面程序需要 **QDM 0.2.1 或更高版本**。扩展为 Manifest V3，适用于 Chromium 114+。这是可加载的开发版，尚未发布到应用商店。

已安装旧版时，在扩展管理页点击“重新加载”，并允许新增的“管理下载”权限。只刷新普通网页不会更新扩展的权限和监听器。原有配对信息会保留，设置中的“自动接管浏览器下载并打开 QDM”默认开启。

## 加载扩展

1. 在 Chrome 地址栏输入 `chrome://extensions`，或在 Edge 输入 `edge://extensions`。
2. 开启开发者模式，点击“加载已解压的扩展程序”（Chrome 为“加载已解压的扩展程序”/“加载已解压的扩展”）。
3. 选择项目的 `D:\project\QDM\browser-extension` 文件夹；使用 ZIP 时先解压，再选择含 manifest.json 的文件夹。
4. 将 QDM 固定到浏览器工具栏。扩展 ID 应为 `nkblcdnjneadmggjpnjajlbebpbmhjpj`，manifest 中的公开 key 用于保持此 ID。

## 连接方式一：本机宿主

先启动桌面程序，然后在 PowerShell 执行（无需管理员）：

```powershell
& 'D:\project\QDM\scripts\register-native-host.ps1'
```

默认同时为当前用户的 Chrome 和 Edge 注册本机宿主，指向 build/release/bin/QDM.NativeHost.exe。注册后在扩展“连接设置”中选择“本机宿主”，点击“测试连接”。

自定义安装目录或桌面数据目录：

```powershell
& 'D:\project\QDM\scripts\register-native-host.ps1' -Browser Chrome -QdmDir 'D:\apps\QDM'
# 只有桌面程序本身也使用 --data-dir 时，才需要指定同一个目录：
& 'D:\project\QDM\scripts\register-native-host.ps1' -DataDir 'D:\my-qdm-data'
```

修改程序位置后重新注册。卸载宿主注册可使用同一脚本的 `-Unregister`，它保留应用和已下载文件。扩展自身在浏览器管理页移除。

## 连接方式二：便携配对

不希望注册宿主时使用此方式：

1. 打开 QDM，点击工具栏“浏览器扩展”。
2. 选择扩展下载目录和默认并发上限，保存。
3. 点击“复制便携配对信息”。
4. 打开扩展“连接设置”，选择“便携配对”，粘贴配对信息，保存并测试连接。

配对信息包含本机密钥，只粘贴到自己的 QDM 扩展，不要交给网页或其他应用。桌面默认监听 127.0.0.1:17878；改变端口或数据目录后需要重新配对。

## 使用

- 正常访问网页、加载图片或播放直接音视频后，点击扩展图标查看当前页面资源。
- 直接点击网页下载链接即可自动交给 QDM，不需要再打开扩展列表点一次下载。交接时浏览器先暂停，QDM 保存任务后再取消浏览器传输，并唤回软件选中新任务。
- QDM 未连接或配对失效时，扩展恢复浏览器原下载；浏览器不允许暂停或已经完成的小文件留在浏览器中。浏览器可能保留一条已取消记录，扩展不删除用户下载历史。
- Native 模式可在收到下载任务时启动同目录 QDM.exe；便携配对模式需要桌面程序已经运行。窗口激活仍遵循 Windows 的前台规则，Native 宿主会尽力交接激活许可。
- “扫描页面”补充识别 DOM 中已有的链接、图片和媒体地址；浏览器内部页面不能扫描。
- 在资源列表点击“下载”，任务会交给桌面程序，显示“已添加”。保存目录由桌面配置决定。
- 可右键链接、图片或音视频，选择“使用 QDM 下载”。右键失败时徽标显示 `!`，打开弹窗查看原因。
- 支持在弹窗手动粘贴 HTTP/HTTPS 地址；视频、音频、图片、文件和流媒体可分别筛选。
- 重复发送同一个资源会返回原任务，不重复创建；清空资源或重新导航后可产生新的请求。

## 支持范围与隐私

支持普通 HTTP/HTTPS 文件和直接音视频文件。m3u8/MPD 清单会单独标记，可以复制地址；当前桌面版尚未支持合并，按钮不会将清单冒充完整视频下载。

扩展不能保证发现所有 Blob、加密、DRM 或登录资源。不读取 Cookie、不转发浏览器登录凭据。自动接管仅处理普通 HTTP(S) 下载，已知 POST、其他扩展创建、隐私窗口、用户已暂停及浏览器标记不安全的下载不接管；可在设置中关闭自动接管，继续保留资源列表/右键功能。

资源只保存在 storage.session，导航或关闭标签后清除，关闭浏览器后消失；每标签最多 100 条、全局最多 400 条。设置和便携密钥只保存在本机 storage.local，不做账户同步、不上传浏览记录。尚未完成的交接记录也保存到 local，但仅包含下载 ID、幂等编号、阶段和时间，不另存 URL/文件路径；交接结束后删除。桌面配对密钥使用 Windows 当前用户 DPAPI 保护。

权限用途：webRequest/HTTP(S) 主机权限用于观察资源响应及识别近期 POST；activeTab/scripting 只在点击扫描时读取页面地址；contextMenus 提供右键菜单；storage 保存候选项、设置和交接阶段；nativeMessaging 仅用于本机宿主；downloads 用于暂停、恢复、确认后的取消；alarms 用于恢复未结束交接。扩展没有远程代码、外部网站消息入口或 Cookie 权限。

## 开发入口

model.js 为纯分类、命名和配对校验；takeover.js 为有持久化意图记录的交接状态机；background.js 为 MV3 生命周期、状态串行化和桌面消息；popup/options 为界面；scan.js 为按需 DOM 读取。以上手工源码已增加详细中文函数/流程注释。桌面协议和验证记录见项目 docs/浏览器扩展设计.md。
