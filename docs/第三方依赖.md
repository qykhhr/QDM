# 第三方依赖与分发记录

当前包为本机开发预览，外部正式发布前仍需完成所用 Qt/ANGLE/字体图像插件、curl 内静态依赖和运行库的完整分发材料核对。

| 项目 | 当前来源与处理 |
| --- | --- |
| Qt 5.8.0 | 使用 D:\Qt\Qt5.8.0 的 msvc2013_64 动态库；本机未重编译 Qt；windeployqt 会修补运行时前缀 |
| Qt 原始源码 | https://download.qt.io/archive/qt/5.8/5.8.0/submodules/ ，按实际部署模块取得同版本源码及许可文件 |
| Qt 许可 | 本机 D:\Qt\Qt5.8.0\Licenses，和对应 Qt 5.8.0 源码内的许可文本 |
| curl 官方 Windows DLL | third_party/curl/curl-8.23.0_9-win64-mingw/COPYING.txt，附属依赖许可在 dep/ 中 |
| curl 构建明细 | 同目录 BUILD-MANIFEST.txt、BUILD-HASHES.txt；保持上游原文 |
| SQLite | third_party/sqlite/sqlite-amalgamation-3540100，源码头声明 public domain |
| MSVC 2013 CRT | 本机 VC/redist/x64/Microsoft.VC120.CRT，构建脚本拷贝 msvcp120.dll 和 msvcr120.dll |
| yt-dlp/ffmpeg | 0.1.0 尚未引入；不能用本项目界面宣称已有站点解析能力 |

根目录 dependencies.lock 和 scripts/bootstrap.py 记录下载来源及上游摘要。不得只依据“动态链接”或“通过独立进程调用”推断已完成全部分发义务。
