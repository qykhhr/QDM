# QDM 0.1.0 验证记录

日期：2026-11-14。系统：本机 Windows x64。构建：Qt 5.8.0 / msvc2013_64，MSVC 2013 v120 Release。

## 构建

`scripts/build.cmd` 执行成功，输出 `build/release/bin/QDM.exe`。libcurl 通过官方 DEF 生成 v120 可用的 C ABI 导入库，SQLite 3.54.1 源码由 v120 编译。运行目录已收集 Qt DLL、qwindows 插件、curl DLL 和 VC120 CRT。

构建日志保存在 build/build.log。依赖来源和摘要见 dependencies.lock，已下载的两份官方归档分别通过 SHA-256 / SHA3-256 校验。

## 集成测试

执行命令：`python tests/integration.py`。

最终成功轮次目录：`tests/work/a797bc6bf2`，其中 results.json 保存原始结果；各场景保留输出文件及独立任务数据库。

## HTTPS 与 GUI

- 使用 EXE 的 headless 模式下载 curl 官方 `https://curl.se/robots.txt`，证书链和主机名校验开启，Windows 系统 CA 启用；与独立 Python HTTPS 请求的 SHA-256 一致。
- 实际启动 Qt Widgets 窗口，检查中文显示、任务表、新建表单、目标路径选择字段。
- 经 GUI 填入同一公开 HTTPS 地址，保存至仓库 build/gui-smoke/robots.txt，界面显示 Completed/66 B/100%，文件内容正确。
- Ctrl+Q 保存退出后成功重新链接 EXE，确认原进程已释放输出程序文件。
